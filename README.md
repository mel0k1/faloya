# Faloya

![ci](https://github.com/mel0k1/faloya/actions/workflows/ci.yml/badge.svg)

Faloya - язык программирования, собранный на базе [Goose](https://github.com/aardappel/goose) Вутера ван Оортмерсена. Исходники - файлы `.fal`, компилятор - один бинарь на C++, программы компилируются в читаемый C и работают как нативный код.

От Goose здесь основа: память без аллокатора, сборщика мусора и аннотаций времён жизни, проверки безопасности на этапе компиляции, скорость на уровне C++. Своё - синтаксические надстройки, которых в Goose не было.

## Что добавил Faloya

Строковая интерполяция:

```
fn main() {
    let name = "мир";
    let year = 2026;
    print("Привет, ${name}! Уже ${year} год.");
}
```

Внутри `${}` работает любое выражение: `${2 + 2}`, вызовы функций, вложенные строки. Соседние подстановки `${a}${b}` склеиваются без разделителей. Кавычка внутри `${}` открывает обычную вложенную строку. Литеральный `${` записывается как `\$`. Сырые строки `"""..."""` не интерполируются.

Такая строка превращается в вызов встроенной функции `str("Привет, ", name, "!")`, которая собирает строку из частей. Интерполяция доступна без импортов и не стоит ничего сверх обычного `str`.

## Сборка

Нужны CMake версии 3.27 или новее и компилятор с поддержкой C++20: gcc, clang или MSVC. Работает на Linux, macOS и Windows.

```
cmake -B build
cmake --build build -j
```

## Запуск

```
build/faloya program.fal
build/faloya build program.fal
```

Первая команда компилирует и запускает программу через встроенный бэкенд на TinyCC, вторая оставляет сгенерированный `program.c` для обычного C-компилятора.

## Тесты

```
python3 test/run.py --exe build/faloya
python3 samples/run_samples.py --exe build/faloya -j 4
```

Первые - кейсы самого языка в `test/`, вторые - 27 сэмплов из `samples/`, каждый в двух режимах: компиляция в C и запуск через JIT. Сэмплы с графикой пропускаются там, где нет SDL и GPU.
