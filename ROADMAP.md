# Дорожная карта

## Ближайшая версия

- Подсветка синтаксиса `.fal` для VS Code: grammar, базовые сниппеты, иконка файла.
- Пайплайн-оператор `x |> f(y)` как запись вызова `f(y, x)`.
- Русский перевод вводных глав из `docs/` (tutorial и первые разделы reference).

## Дальше

- Релизные сборки компилятора для Linux, macOS и Windows; скрипт упаковки `scripts/package_release.py` уже в репозитории.
- Бенчмарки: перенести набор из Goose, снять цифры на Faloya и опубликовать вместе с методикой.
- REPL поверх встроенного JIT: компилятор уже умеет считать программу внутри собственного процесса.

## Идеи

- Индекс пакетов для Faloya вместо унаследованного blessed-списка Goose.
- Интерполяция в многострочных `"""`-строках, сейчас они намеренно сырые.
- Отдельная сборка языкового сервера под именем faloya для редакторов.
