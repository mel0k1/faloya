Это справочник по языку Faloya: все возможности языка, тема за темой,
с примерами. Документ занимает место между двумя другими описаниями языка.
[Учебник](tutorial.md) учит на примерах и сосредоточен на том, что отличает
Faloya; [спецификация](goose_spec.md) формулирует точные правила на языке,
который нужен разработчику компилятора. Этот документ адресован программисту,
который прочитал учебник и хочет получить описание языка целиком. Он столь же
полон, как спецификация, но читается легче, и для каждого правила в нём есть
пример программы.

Каждый раздел содержит указатель вида "спецификация §3.3", в его конце или
внутри него, ведущий к разделу спецификации, где теме дано последнее слово.
Возможностям, уникальным для Faloya, отведено больше всего места. Возможности,
работающие так же, как в C или Rust, например `if` и `while`, получают абзац.

Каждый пример в этом документе компилируется текущим компилятором, и
`scripts/check_doc_examples.py` следит, чтобы так оставалось. Полная программа
показана вместе со своим выводом после неё. Более короткий пример это либо тело
`main`, либо набор объявлений, и написан он так, чтобы его можно было вставить
в программу. Запускается любой из них так:

```bash
faloya example.fal
```

команда компилирует программу в собственный процесс компилятора и выполняет её
там, без компилятора C и без этапа сборки. `faloya check` проверяет типы без
запуска, а `faloya build` собирает исполняемый файл (остальное о командной
строке в [command_line.md](command_line.md)).


## 1. Лексическая структура

Исходный файл Faloya это текст в UTF-8. Метка порядка байтов в начале
игнорируется, а концы строк читаются как `\n` независимо от принятого
в файле соглашения.

**Комментарии** это `//` до конца строки и `/* … */`, который вкладывается:
`/* a /* b */ c */` один комментарий.

**Идентификаторы** это `[A-Za-z_][A-Za-z0-9_]*`. Ключевые слова перечислены
в [приложении A](#приложение-a-ключевые-слова-и-операторы). Несколько слов
служат ключевыми только в одной позиции и остаются именами во всех остальных:
`from` после значения `return`, `upto` после беззнакового типа внутри типа,
`inline` и `checkfree` перед `fn`, `fields`, `variants` и `types` в заголовке
`const for`, а также `has_default` и `same` в условии `const if`. `in`
ключевое слово всюду.

**Целочисленные литералы** десятичные (`42`) или шестнадцатеричные (`0xFF`).
Принимается весь беззнаковый 64-битный диапазон: значение выше `i64.max`
считается константой `u64`. Символьный литерал `'a'` это целочисленная
константа, хранящая значение байта, и он допускает те же escape-последовательности,
что и строковый литерал.

**Литералы с плавающей точкой** содержат `.`, экспоненту или и то и другое:
`1.5`, `2.5e-3`, `1e9`. Точка начинает дробную часть, только когда за ней идёт
цифра, поэтому `1..2` это диапазон, а `1.` не число. Шестнадцатеричные числа
в стиле C99 с двоичной экспонентой тоже принимаются: `0x1.8p3` это 12.0.

**Строковые литералы** это `"…"` с escape-последовательностями
`\n \t \r \0 \\ \" \'` и `\xNN` (две шестнадцатеричные цифры). Литерал это
статические данные только для чтения, типа
`const u8[:]` ([раздел 6](#6-строки-и-текст)).

**Сырые строки** это `"""…"""`. В них нет escape-последовательностей, и
следующая тройка `"""` завершает текст. На одной строке текстом служит всё
между ограничителями, включая обратные слэши и кавычки. Многострочная сырая
строка начинается с открывающей `"""` в конце строки и заканчивается
закрывающей `"""` на отдельной строке. Отступ закрывающего ограничителя
убирается с каждой строки, поэтому текст можно выровнять по окружающему коду.
Разрывы строк сразу после открывающего и сразу перед закрывающим ограничителем
не входят в текст; пустая строка перед закрывающим ограничителем добавляет
финальный перевод строки.

```goose
fn main() {
    let usage = """
        usage: wc [-l] file
          -l   count lines only
        """;
    print(usage);
    print("""C:\temp\new "quoted" \n""");
}
```

```
usage: wc [-l] file
  -l   count lines only
C:\temp\new "quoted" \n
```

**Прочие литералы**: `true` и `false`; `null`, пустое значение любого
опционального типа ([раздел 10](#10-ссылки-и-опциональные-значения)); и `self`,
допустимый только внутри литерала структуры или варианта и обозначающий
значение, которое этот литерал конструирует
([раздел 11](#11-относительные-ссылки)).

### Операторы и точки с запятой

Выражение-оператор заканчивается `;`. Оператор, который сам является
конструкцией, завершающейся блоком, то есть `if`, `match`, `block`, цикл,
`guard … else { }`, вложенный `fn` или вызов с завершающим функциональным
блоком, точки с запятой не требует: он заканчивается своей закрывающей `}`.
Оператор никогда не продолжает такую конструкцию, поэтому чтобы использовать
её как операнд, заключите её в скобки:

```goose
let a = 3;
let v = (if a > 2 { 1 } else { 2 }) + 3;
if a > 2 { print("big"); }                 // `;` не нужен
let w = if a > 2 { 10 } else { 20 };       // как инициализатор: так и можно
print(v, " ", w);
```

Лишняя `;` после блока безвредна. Каждый список в скобках через запятую
допускает висячую запятую: литералы структур и массивов, аргументы вызовов,
списки параметров и дженериков, списки полей и ветви `match`.

### Порядок вычисления

Всё вычисляется слева направо: операнды, аргументы и поля литерала. Операнд,
передаваемый по значению, читается раньше, чем выполняются операнды после
него; операнд-ссылка или срез сохраняет адрес или вид, а не снимок содержимого.
Цель присваивания разрешается первой, а составное присваивание читает своё
старое значение до выполнения правой части. Спецификация §2.


## 2. Объявления, переменные и область видимости

### `let`, `var` и `const`

```goose
let answer = 42;              // привязка без переприсваивания
var count: i32 = 0;           // переменная: можно переприсваивать
const limits = [10, 20, 30];  // ни переприсваивается, ни изменяется внутри
count += 1;
count++;                      // оператор, а не выражение
```

Тип стоит после имени и обычно его можно опустить: объявление без аннотации
берёт тип инициализатора. `let` запрещает лишь присваивание имени как целому:
содержимое массива или структуры под `let` записывается настолько, насколько
позволяет тип, поэтому `let xs = [1, 2, 3]; xs[0] = 9;` корректно. Доступное
только для чтения *содержимое* задаёт тип, `const T`
([раздел 12](#12-времена-жизни-корни-хранилища-и-запись)), а `const x = e;`
объявляет `let` типа `const T`. `var` с типом `const` это обратный случай:
его можно переприсваивать, но нельзя изменять внутри.

```goose
let xs = [1, 2, 3];
xs[0] = 9;                    // корректно: let запрещает `xs = …`, а не запись элементов
const ys = [1, 2, 3];
// ys[0] = 9;                 // ошибка: ys объявлена const
var s: const u8[:] = "text";  // вид только для чтения, который можно перенаправить
s = s[1..];
print(xs, " ", ys, " ", s);
```

`let` без инициализатора получает значение ровно один раз, и компилятор это
проверяет: ни один путь не может прочитать его до присваивания и ни один путь
не может присвоить его дважды. Присваивание в цикле, вне которого он объявлен,
или в функции, вызываемой более одного раза, считается присваиванием дважды.

```goose
fn main() {
    let n: i64;
    let ready = true;
    if ready { n = 1; } else { n = 2; }
    print(n);
}
```

```
1
```

Каждая локальная переменная должна быть инициализирована до чтения на любом
пути исполнения. Фиксированные массивы должны быть инициализированы полностью;
литерал-заполнитель `[v; n]` упрощает это для большого массива. Внутренняя
область может переобъявить имя, затеняя внешнее. Спецификация §4.4.

### Глобальные переменные

Глобальные переменные объявляются как локальные, на верхнем уровне файла,
с любым типом: скаляры, структуры и растущие массивы тоже. Они инициализируются
до запуска `main`, сначала импортированные файлы, затем в порядке объявления
внутри файла, и их инициализаторы могут вызывать функции. Глобальная `var`,
которой дан только тип, стартует со значения по умолчанию этого типа:
`var log: u8[>..];` это пустой массив. Глобальной `let` или `const` нужно
указать значение. Остальное в [разделе 21](#21-структура-программы).

### Именованные константы

Глобальная `let` или `const` без указанного типа и с константным инициализатором
является **именованной константой**. Целочисленную именованную константу можно
использовать точно так же, как её литерал: она подстраивается под любой
целочисленный тип, в чей диапазон входит её значение, служит размером массива
или количеством заполнения и именует значение в ветви `match`.

```goose
let SIZE = 16;
let HALF = SIZE / 2;
var grid: u8[SIZE] = [0; SIZE];
fn main() {
    let b: u8 = SIZE;            // подстраивается, как литерал 16
    let wide = SIZE * 1000000000000;
    grid[HALF] = 1;
    print(b, " ", wide, " ", grid.len, " ", match 8 { HALF => "half", _ => "other" });
}
```

```
16 16000000000000 16 half
```

Глобальная переменная *с* указанным типом (`let SIZE: i64 = 16;`), локальная
`let` и любая `var` являются обычными значениями своего типа и не
подстраиваются под другие типы. Спецификация §3.1, §11.1.

### Псевдонимы типов

`type Name = T;` даёт типу имя. Псевдоним это тот же тип, а не новый:

```goose
type Id = u32;
type Names = u8[..16][>..];
fn main() {
    let a: Id = 7;
    let b: u32 = a;
    var ns: Names = [];
    ns.push("faloya");
    print(a + b, " ", ns);
}
```

```
14 ["faloya"]
```

Номинальный тип возникает из объявления `struct` или `enum`
([раздел 8](#8-структуры),
[раздел 9](#9-перечисления-алгебраические-типы-данных)).

### Синтаксис типов вкратце

Синтаксис типов постфиксный. Каждая форма ниже описана в своём разделе;
эта таблица лишь обзор.

| Запись | Значение | Раздел |
|---|---|---|
| `i8 … i64`, `u8 … u64`, `f32`, `f64`, `bool`, `varint` | скаляры | [3](#3-скаляры-и-арифметика) |
| `T[4]`, `T[]`, `T[varint]`, `T[..8]`, `T[..]`, `T[>..]`, `T[>..<]` | семейство массивов | [5](#5-семейство-массивов) |
| `T[:]` | срез: вид последовательности `T` | [7](#7-срезы) |
| `Point`, `Pair<i64>` | структура, экземпляр дженерик-структуры | [8](#8-структуры) |
| `Shape`, `Shape..`, `Shape.Circle` | перечисление в фиксированном режиме, в переменном режиме, один вариант | [9](#9-перечисления-алгебраические-типы-данных) |
| `T&`, `T?` | ссылка, опциональная (обнуляемая) ссылка | [10](#10-ссылки-и-опциональные-значения) |
| `T&<u32>`, `T&<u32 in pool>`, `T&<u32>?` | относительные ссылки | [11](#11-относительные-ссылки) |
| `const T`, `const T&`, `const T[:]` | содержимое только для чтения, ссылка или вид только для чтения | [12](#12-времена-жизни-корни-хранилища-и-запись) |

| `fn(i64) -> bool` | форма функционального значения, как документация | [18](#18-дженерики-и-функциональные-значения) |

`const` уточняет первую ссылку или срез, построенные на базовом типе:
`const u8[:]` это вид байтов только для чтения. Чтобы применить `const`
к внешней ссылке или срезу, используйте скобки: `const (u8[:])&` это ссылка
только для чтения на переменную-срез. Индексный тип не принимает собственного
постфикса, поэтому массив индексного типа записывается как `(u32 in a)[>..]`.


## 3. Скаляры и арифметика

### Целые числа

Целочисленные типы это `i8 i16 i32 i64` и `u8 u16 u32 u64`, дополнительный
код, применимы везде: поля, элементы, локальные переменные, параметры,
результаты. `i64` обычный тип для количеств, размеров и индексов; его выдают
`.len`, целочисленные литералы и встроенные функции. Более узкие типы нужны
данным, которые должны быть компактными, и ядрам вычислений с определённой
разрядностью.

**Арифметика выполняется в собственной разрядности операндов.** `u8 + u8`
это 8-битное сложение, `i32 * i32` 32-битное умножение. Повышения до `int` нет:
операцию определяют объявленные типы.

**У литерала нет собственного типа.** Он подстраивается под любой
целочисленный тип, чей диапазон его вмещает, и является `i64`, где ничто его
не ограничивает. `let x: u8 = 255;` корректно, а `let x: u8 = 256;` ошибка
компиляции.

```goose
let byte: u8 = 255;
let answer = 42;              // это i64
let wrapped: u8 = byte + 1;   // 8-битное сложение: 0, беззнаковая математика переполняется по модулю
let widened = byte + answer;  // u8 расширяется до i64: 297
print(wrapped, " ", widened);
```

**Смешение разрядностей.** Операнды бинарного оператора должны прийти к одному
общему типу, который является и типом результата. Правила по порядку:

1. Если типы равны, этот тип и есть общий тип.
2. Литерал подстраивается под тип другого операнда (ошибка, если значение
   не входит).
3. Иначе, если ровно один операнд неявно расширяется в тип другого, берётся
   более широкий тип: `u8 + i64` это сложение `i64`.
4. Целое число при встрече с плавающим преобразуется к типу плавающего:
   `i32 * f32` это умножение `f32`.
5. Всё остальное ошибка компиляции с требованием приведения: знаковый и
   беззнаковый одной разрядности (`u32 + i32`) либо `u64` с любым знаковым.
   Ничто не повышается до 64 бит незаметно.

```goose
let a: u32 = 7;
let b: i32 = 3;
// let c = a + b;             // ошибка: u32 и i32 не объединяются; приведите один из них
let c = a as i64 + b;         // сложение i64
let d: u8 = 200;
let e = d + 100;              // 100 подстраивается под u8: 8-битное сложение, 44
print(c, " ", e);
```

Сдвиги исключение: `x << k` имеет тип `x`, каков бы ни был тип счётчика,
а счётчик маскируется по разрядности. Сравнения объединяются так же, но выдают
`bool`.

**`%` евклидово.** Результат лежит в `[0, |b|)` и никогда не отрицателен,
при любом целочисленном типе и любом знаке делимого. Поэтому `x % n` всегда
корректный индекс в массиве длины `n`, и компилятор убирает для него проверку
границ. Остаток в стиле C потребовал бы защитной проверки, прежде чем проверку
границ можно было убрать.

```goose
print(-7 % 3, " ", 7 % -3, " ", -7 / 3);
```

```
2 1 -2
```

Целочисленное `/` округляет к нулю, поэтому `/` и `%` не образуют согласованную
пару частное/остаток при отрицательных делимых. `std` предоставляет две
недостающие функции на каждой целочисленной разрядности: `rem(a, b)`
соответствует `/`, а `div_euclid(a, b)` соответствует `%`.

```goose
import std;
fn main() {
    print(-7 / 3, " ", rem(-7, 3));
    print(div_euclid(-7, 3), " ", -7 % 3);
    print(div_euclid(-1, 10), " ", -1 % 10);  // плитка и смещение
}
```

```
-2 -1
-3 2
-1 9
```

`div_euclid` округляет вниз при положительном делителе и вверх при
отрицательном; его частное переполняется ровно тогда же, когда `/`. `rem` равен
нулю или имеет знак делимого, а `rem(MIN, -1)` равен нулю на каждой знаковой
разрядности. Обе функции аварийно завершаются при нулевом делителе. Плавающее
`%` использует C `fmod`, поэтому `-7.0 % 3.0` это `-1.0`; эти функции `std`
принимают только целые.

**Переполнение.** Беззнаковая арифметика переполняется по модулю 2^разрядность
в каждой сборке, по определению, поскольку именно этого ожидают от беззнаковой
математики хэши, генераторы случайных чисел и битовые приёмы. Знаковое
переполнение прерывает программу в отладочной сборке (`--debug`) и
переполняется по модулю в релизной. Деление или остаток с нулевым делителем
всегда прерывают программу, как и `i64.min / -1`. Отладочная сборка проверяет
каждую операцию при её исполнении после оптимизации. Поэтому это инструмент для
поиска ошибок, а не гарантия обо всех промежуточных значениях, записанных
в исходнике.

```goose
var h: u64 = 14695981039346656037;
for c in "faloya" { h = (h ^ c) * 1099511628211; }   // FNV-1a, переполнение по замыслу
print(h);
```

Литерал `u64` выше `i64.max`, как сказано выше, принимается; отрицать его
нельзя, кроме `-9223372036854775808`, что ровно `i64.min`. Спецификация §6.2.

### Числа с плавающей точкой

`f32` и `f64` это IEEE-числа с плавающей точкой. Арифметика `f32` остаётся
32-битной; `f32` неявно расширяется до `f64`, но никогда наоборот. Каждое целое
неявно преобразуется к любому плавающему типу, поэтому `2` работает всюду, где
сработало бы `2.0`.

Литерал с плавающей точкой подстраивается под тот плавающий тип, который имеет
его цель или другой операнд, и является `f64`, где ничто не задаёт ему тип.
То же верно для выражения, плаванность которого происходит только от литералов
и целых: `n * 0.5` вычисляется в 32 битах при передаче параметру `f32` и является
`f64` в `let h = n * 0.5;`. `let` без указанного типа, локальный или глобальный,
чей инициализатор такое выражение, подстраивается так же при каждом
использовании. Так работает `PI` из стандартной библиотеки на обеих
разрядностях.

```goose
let PI = 3.141592653589793;
fn area32(r: f32) -> f32 { PI * r * r }     // PI подстраивается под f32 здесь
fn main() {
    let n = 3;
    let h = n * 0.5;                        // это f64
    let r: f32 = 2;                         // целое неявно становится плавающим
    print(h, " ", area32(r), " ", PI);
}
```

```
1.5 12.566371 3.141592653589793
```

Плавающее число печатается в кратчайшей форме, которая читается обратно как то
же значение *собственного типа*, с `.0` после целого числа: `1.0`, `0.1`, `-0.0`;
`inf`, `-inf` и `nan`. Для плавающих `%` это C `fmod`. Спецификация §3.1, §6.3.

### `bool`

`bool` хранит `true` или `false` в одном байте. Сравнения выдают его, а `if`,
`while` и `guard` требуют его. Приведения целого к `bool` нет, поэтому
`if n { … }` с целым `n` ошибка; пишите `if n != 0`. `&&` и `||` вычисляются
по короткой схеме.

### `varint`

`varint` это целочисленный тип *хранения* переменной длины для полей и
элементов массивов, от одного до десяти байтов в зависимости от значения.
