# Faloya для VS Code

Расширение для языка Faloya: подсветка синтаксиса, сниппеты, иконка файлов `.fal`, задачи компилятора и диагностика ошибок прямо в редакторе.

## Возможности

- Подсветка синтаксиса: служебные слова, типы (`i64`, `f64`, `u8`...), строки с подсветкой интерполяции `${...}`, оператор пайплайна `|>`, вложенные блоки-комментарии.
- Подсветка блоков ``` faloya внутри Markdown-файлов.
- Сниппеты: `fn`, `struct`, `match`, `guard`, `pipe` (`x |> f()`), `interp` (`"${...}"`) и другие.
- Команды (категория Faloya, палитра команд):
  - **Run with JIT** запускает текущий файл в JIT (F5 или Ctrl+Shift+B);
  - **Build Executable** собирает исполняемый файл рядом с исходником;
  - **Check Program** проверяет файл и показывает ошибки как диагностику;
  - **Format File** приводит файл к стандартному оформлению (`faloya format`);
  - **Show Compiler Output** открывает вывод компилятора.
- Диагностика при открытии и сохранении файла: расширение запускает `faloya check` и раскладывает ошибки по строкам.
- Задачи типа `faloya` (run / check / build / format) с problem matcher, то есть ошибки из задач тоже попадают в список проблем.

## Установка

1. Соберите компилятор и положите его рядом с проектом (`build/faloya`) или добавьте в `PATH`.
2. Варианты установки расширения:
   - открыть папку `vscode/` в VS Code и запустить Run Extensions, затем Run Extension (F5);
   - либо собрать VSIX через `npx @vscode/vsce package` и установить через Extensions, пункт Install from VSIX.

Расширение ищет компилятор так: настройка `faloya.compilerPath`, затем `faloya`, `build/faloya`, `build/Release/faloya`, `build/Debug/faloya` внутри рабочей папки, затем `faloya` из `PATH`.

## Настройки

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `faloya.compilerPath` | пусто | Путь к компилятору; поддерживает `${workspaceFolder}` |
| `faloya.entryFile` | пусто | Входной файл проекта, когда редактируете модуль, а не `main` |
| `faloya.useRunKeybindings` | `true` | Запуск по F5 и Ctrl+Shift+B в файлах Faloya |
| `faloya.checkOnSave` | `true` | Проверять файл при открытии и сохранении |
| `faloya.checkTimeout` | `15000` | Таймаут фоновой проверки, мс |
| `faloya.runArguments` | `[]` | Аргументы программы после `--` при запуске |

## Чего пока нет

Клиент language server: компилятор умеет `faloya lsp` (диагностика на вводе, hover, переход к определению), но интеграция с VS Code ещё не подключена и остаётся в [роадмапе](../ROADMAP.md). Сейчас проверка выполняется по сохранению.
